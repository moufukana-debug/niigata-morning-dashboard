# 朝の業務スタート画面

新潟県少年自然の家で朝の確認に使う、スマホ優先のローカルWebアプリです。勤務予定表PDFと調整プログラムExcelをブラウザ上で読み込み、選択した日付の「西村」さんの勤務・団体行事・注意点・最初にやることを1カラムで表示します。

## 作るものの要約

- ローカルで動く単体HTML/CSS/JavaScriptアプリ
- PDF: `260429_R8.05月_勤務予定表.pdf` をファイル選択で読み込み
- Excel: `R8_5月調整プログラム_前半_.xlsx` をファイル選択で読み込み
- 今日の日付に該当する情報だけを優先表示
- メモ欄とチェック項目は `localStorage` に自動保存
- ベージュ、アイボリー、くすみブラウン系のカードUI

## 実装方針

1. まず資料をブラウザ内で読み込みます。サーバーへアップロードしません。
2. PDFはテキストを行単位に並べ、`西村` 行と当日日付列を優先して簡易抽出します。
3. PDFの表構造が崩れる場合は、抽出元を「PDF簡易抽出（要確認）」として表示し、断定しません。
4. Excelは全シートを読み、当日日付に近い行から団体名・時間・活動・場所・備考を推定します。
5. 不足や判定不能な値は必ず `要確認` と表示します。
6. 朝に見る順番として、上から「勤務」「注意点」「最初にやること」「団体・行事」「基本情報」「メモ」にしています。

## 使用技術と理由

- HTML/CSS/JavaScript: 初心者でもファイル構成が分かりやすく、GitHub Pagesへ置きやすいため。
- PDF.js: ブラウザだけでPDFテキストを読み取るため。
- SheetJS: ブラウザだけでExcelファイルを読み取るため。
- localStorage: ローカル環境でメモとチェック状態を保存するため。

## 実装コード

主な実装場所は以下です。

- `index.html`: ファイル選択、勤務、注意点、タスク、団体・行事、メモ欄のHTML
- `styles.css`: 韓国カフェ風の配色、カードUI、スマホ1カラムレイアウト
- `src/app.js`: PDF/Excel解析、今日の日付抽出、`要確認` 表示、localStorage保存

## 起動方法

### ローカルサーバーで開く方法（おすすめ）

PDF.jsなどのライブラリを安定して読み込むため、ローカルサーバーで開く方法をおすすめします。

```bash
python3 -m http.server 8000
```

その後、ブラウザで次を開きます。

```text
http://localhost:8000
```


### GitHub Pages project siteで開く場合

このリポジトリは project site として、次のURLで動く前提です。CSSとJavaScriptは `./styles.css` と `./src/app.js` の相対パスで読み込みます。

```text
https://moufukana-debug.github.io/niigata-morning-dashboard/
```

## 使い方

1. 「勤務予定表PDF」で `260429_R8.05月_勤務予定表.pdf` を選びます。
2. 「調整プログラムExcel」で `R8_5月調整プログラム_前半_.xlsx` を選びます。
3. 必要に応じて「確認する日付」を変更します。
4. まず「今日の勤務」と「注意点」を確認します。
5. 「最初にやること」を3つだけチェックします。
6. 気づいたことは「ひとことメモ」に書きます。
